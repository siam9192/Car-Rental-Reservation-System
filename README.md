
# 🚗 Car Rent Web App

A simple web application that allows users to browse, book, and manage car rentals, along with an admin panel for vehicle and booking management.

---

## ✨ Features

### 🧑‍💼 User Panel

- User registration and login
- Browse available cars
- Search and filter by brand, type, or availability
- View detailed car information (model, price, images, features)
- Book or rent a car
- View current and past bookings
- Cancel or update upcoming bookings

### 🛠️ Admin Panel
- Dashboard with rental statistics and summaries
- Add, edit, and delete car listings
- Manage car availability
- View, edit, or cancel bookings
- Manage user accounts
- View revenue and booking reports

---

## 🏗️ Tech Stack

| Layer       | Technology                     |
|-------------|--------------------------------|
| Frontend    | React js,Redux|
| Backend     | Node.js + Express|
| Database    | MongoDB   |
| Authentication | JWT|
| Styling     | Tailwind CSS       |
